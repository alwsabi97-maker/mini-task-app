# منصة التعلم

تطبيق تعليمي بسيط مصمم لتوضيح فكرة لوحة التعلم والتقدم اليومي.

## المميزات
- واجهة عربية كاملة
- أقسام: الرئيسية، الدروس، الاختبار السريع
- عرض درس مختار مع نقاطه
- اختبار سريع مع حساب النتيجة
- تصميم متجاوب للجوال

## التشغيل
يمكنك فتح الملف `index.html` مباشرة في المتصفح، أو استخدام خادم بسيط:

```bash
python3 -m http.server 8000
```

ثم افتح الرابط التالي في المتصفح:

```text
http://localhost:8000
```

## الملفات
- `index.html` — هيكل الصفحة
- `styles.css` — تصميم الواجهة
- `script.js` — منطق الدروس والاختبار

## الهدف
هذا المشروع مناسب كبدء تعليمي بسيط لتعلم HTML + CSS + JavaScript بطريقة عملية ومباشرة.
